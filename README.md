# cacastopia

I build tools for working with AI coding agents, learning from code, and everyday routines.

[Medium](https://medium.com/@adventuresol) · [Velog](https://velog.io/@cacastopi/posts)

## Projects

| Project | What it does |
| --- | --- |
| [make-my-textbook](https://github.com/ganggangstone/make-my-textbook) | Custom textbooks for the AI era. Turn code and papers into a study textbook at your level, with every sentence graded by source. |
| [agent-hud](https://github.com/ganggangstone/agent-hud) | A local dashboard for your coding agents' skills, instructions, and plugin state. |
| [where-were-we](https://github.com/ganggangstone/where-were-we) | Local codebase maps and change impact analysis for humans and AI agents, with an MCP server. |
| [hamstretch](https://ganggangstone.github.io/hamstretch/) (기지개햄) | A hamster nudges you to rest your eyes and stretch every 20 minutes. A macOS / Windows menu bar app. |
| [i-am-good](https://github.com/ganggangstone/i-am-good) | A Toss mini app that turns compliments into applause when you shout them out in the morning. |
| [stop-slop-ko](https://github.com/ganggangstone/stop-slop-ko) | Fork of [limleesol/stop-slop-ko](https://github.com/limleesol/stop-slop-ko), a Claude skill that removes AI-sounding style from Korean prose. |
